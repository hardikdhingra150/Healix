## ✨ Features

### For Patients 🧑‍⚕️
- ✅ **Health Vitals Tracking** - Log blood pressure, heart rate, temperature, oxygen levels, and weight
- 📊 **Interactive Dashboard** - View health metrics with beautiful visualizations
- 📈 **Health Trends** - 7-day trend analysis with charts
- ⚠️ **Smart Health Alerts** - Automatic warnings for abnormal vitals
- 👤 **Profile Management** - Manage personal and medical information
- 🌙 **Dark Mode** - Eye-friendly dark theme
- 📱 **Responsive Design** - Works seamlessly on desktop, tablet, and mobile

### For Doctors 👨‍⚕️
- 📋 **Patient Management** - View all registered patients in one dashboard
- 🔍 **Search & Filter** - Quickly find patients by name or email
- 📊 **Analytics Dashboard** - Comprehensive health trend visualization for each patient
- 🚨 **Alert System** - Identify patients needing immediate attention
- 📈 **Multi-Patient Monitoring** - Track multiple patients simultaneously
- 📉 **Health Trend Charts** - Blood pressure, heart rate, temperature, and oxygen level trends

### General Features 🌟
- 🔐 **Secure Authentication** - Email/password and Google OAuth
- 🔥 **Real-time Data** - Firebase Firestore for instant updates
- 🎨 **Modern UI/UX** - Clean, intuitive interface with smooth animations
- 🌍 **Multi-user Support** - Separate portals for patients and doctors
- 📱 **Progressive Web App** - Install on mobile devices
- 🔒 **HIPAA-Compliant Ready** - Secure data handling and privacy

## 🛠️ Tech Stack

### Frontend
- **React 18** - UI library
- **Vite** - Build tool and dev server
- **React Router** - Client-side routing
- **Recharts** - Data visualization
- **Lucide React** - Icon library
- **CSS3** - Styling (no Tailwind, pure CSS)

### Backend & Services
- **Firebase Authentication** - User authentication
- **Cloud Firestore** - NoSQL database
- **Firebase Hosting** - (Optional) Static hosting

### DevOps
- **Vercel** - Deployment platform
- **Git** - Version control
- **npm** - Package manager

## 📋 Prerequisites

Before you begin, ensure you have the following installed:

- **Node.js** (v16.x or higher) - [Download](https://nodejs.org/)
- **npm** (v8.x or higher) - Comes with Node.js
- **Git** - [Download](https://git-scm.com/)
- **Firebase Account** - [Sign up](https://firebase.google.com/)

## 🚀 Installation

### 1. Clone the Repository
```bash
git clone https://github.com/yourusername/healthcare-monitoring.git
cd healthcare-monitoring
```

### 2. Install Dependencies
```bash
npm install
```
